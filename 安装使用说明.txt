鸭梨AI图像生成插件（异步接口版）

一、安装
1. 关闭字字动画工具。
2. 将本目录整体复制到工具的：
   _internal\plugins\image_plugins\
   保留 main.py 和 ui 文件夹的目录结构，不要只复制单个文件。
3. 重新启动工具，在图像生成插件列表中打开“鸭梨AI图像生成插件（异步接口版）”。

二、首次配置
1. 点击插件底部的“设置”打开配置窗口。
2. 按所选模型填写 GPT KEY、GEMINI KEY、GROK KEY 或 AGNES KEY。
3. API URL 默认是 https://api.yaliai.com，可按实际网关地址修改并保存。
4. “模型”选择决定使用的接口类型：
   - gpt-image-2：OpenAI Images 接口。
   - gemini-3.1-flash-image-preview、gemini-3-pro-image-preview：Gemini 接口。
   - grok-imagine-image-quality：OpenAI Images 兼容路径，支持 1K/2K 和合法比例，不提交画质字段。
   - agnes-image-2.1-flash：固定使用 /v1/images/generations，支持 1K/2K/3K/4K 和合法比例；参考图按 extra_body.image 提交。
5. 关闭设置窗口后即可在工具的图像生成界面调用。
6. 参考图不超过 5MB 时原样上传；超过 5MB 时才会按比例压缩到 5MB 以下。原始文件不会被修改，超大原图也会尝试压缩，不会因为文件大小直接拒绝。

三、生成模式
1. 默认（单模型）：只调用当前选择的模型。
2. 超分（A 到 B）：先由 A 模型生成临时图，再将临时图作为参考图交给 B 模型；只有 B 的最终结果会返回给工具。
3. B 模型默认是 gemini-3-pro-image-preview，可修改。B 使用其所属接口类型和对应 API Key。
4. A、B 共享的是档位、比例等语义设置；插件会按各自接口规则单独转换请求字段，不会把 OpenAI 的具体像素尺寸直接提交给 Gemini。
5. 超分提示词支持 `{image_size}` 和 `{aspect_ratio}` 变量，分别替换为当前图像档位和图像比例。

四、任务与等待
1. 插件使用鸭梨AI异步接口，首次查询约等待 20 秒，之后约每 2 秒查询一次。
2. 每个模型阶段最长等待 1800 秒；超分模式包含两个阶段，总等待预算为 3600 秒。
3. 批量任务会并行提交，并受插件本地并发上限约束，避免本机带宽和磁盘同时过载。
4. “打开任务日志”可查看模式、模型、档位、比例、画质、提示词预览、状态和结果图片。

五、配置与隐私
1. 第一次启动后，配置保存在工具的 user_resources\plugins\image_plugins\yaliai-async-image-plugin\config.json；API Key 只保存在本机配置中。
2. async_tasks.jsonl 是本机任务日志，不包含完整提示词和图片 Base64。
3. 分发插件时不要携带 config.json、async_tasks.jsonl 或 __pycache__ 文件夹；它们会在运行时自动生成。
4. 任务日志页面的清理操作只清理任务记录，不删除工具已经保存的结果图片。

六、插件更新
1. 在插件底部打开“设置”，点击“检查更新”。
2. 只有远端版本高于本地版本、下载包 SHA-256 校验通过时，才会显示“下载并安装”。
3. 插件存在生成、下载或超分任务时会拒绝安装更新；请等待任务完成后再更新。
4. 更新成功后重启字字动画生效；本机 API Key、任务日志和参考图缓存不会被更新包覆盖。
