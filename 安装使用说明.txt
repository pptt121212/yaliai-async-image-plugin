鸭梨AI图像生成插件（低价版）

一、安装
1. 关闭字字动画工具。
2. 将本目录整体复制到工具的：
   _internal\plugins\image_plugins\
   保留 main.py 和 ui 文件夹的目录结构，不要只复制单个文件。
3. 重新启动工具，在图像生成插件列表中打开“鸭梨AI图像生成插件（低价版）”。

二、首次配置
1. 分别填写 GPT-image-2 API Key 和 Gemini API Key。
2. API 地址固定为 https://api.yaliai.com/，插件界面不允许修改。
3. “模型”选择决定使用的接口类型：
   - gpt-image-2：OpenAI Images 接口。
   - gemini-3.1-flash-image-preview、gemini-3-pro-image-preview：Gemini 接口。
4. 保存后即可在工具的图像生成界面调用。

三、生成模式
1. 默认（单模型）：只调用当前选择的模型。
2. 超分（A 到 B）：先由 A 模型生成临时图，再将临时图作为参考图交给 B 模型；只有 B 的最终结果会返回给工具。
3. B 模型默认是 gemini-3-pro-image-preview，可修改。B 使用其所属接口类型和对应 API Key。
4. A、B 共享的是档位、比例等语义设置；插件会按各自接口规则单独转换请求字段，不会把 OpenAI 的具体像素尺寸直接提交给 Gemini。

四、任务与等待
1. 插件使用鸭梨AI异步接口，首次查询约等待 20 秒，之后约每 2 秒查询一次。
2. 每个模型阶段最长等待 1800 秒；超分模式包含两个阶段，总等待预算为 3600 秒。
3. 批量任务会并行提交，并受插件本地并发上限约束，避免本机带宽和磁盘同时过载。
4. “打开任务日志”可查看模式、模型、档位、比例、画质、提示词预览、状态和结果图片。

五、配置与隐私
1. 第一次启动后，插件目录会自动生成 config.json；API Key 只保存在本机配置中。
2. async_tasks.jsonl 是本机任务日志，不包含完整提示词和图片 Base64。
3. 分发插件时不要携带 config.json、async_tasks.jsonl 或 __pycache__ 文件夹；它们会在运行时自动生成。
4. 任务日志页面的清理操作只清理任务记录，不删除工具已经保存的结果图片。
